## The review

> Item as described: 'genius, low maintenance, sleeps normal hours.' Arrived: loud, high maintenance, and allergic to reading my answers.

135 characters, one line, nothing else. The listing promised a genius;
the delivery is loud, high maintenance, and allergic to reading my
answers — the classic rating-site shape, with the human as the product.

## How it works

`main.ts` (Node, standard library only) writes that exact line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no
randomness — two runs produce byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```
